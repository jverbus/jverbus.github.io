Model and color-scale details

These JavaScript implementations train standard Isolation Forest on the left and fully extended EIF on the right using the same points. Each tree uses a subsample of up to 256 points, with path-length normalization based on the actual subsample size. Higher scores indicate more anomalous points.

The shared color scale uses estimated 2nd and 98th percentiles of both score maps, widened when scores are nearly equal, with a nonlinear color ramp to reveal low-score structure. Scores outside those endpoints use the end colors; the numeric probe always shows the original score.
